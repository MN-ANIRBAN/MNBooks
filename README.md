# 📚 MN Book Library

A modern, full-featured personal book collection management web application built with React and Firebase. Perfect for book enthusiasts who want to catalog their personal library, track reading habits, and manage their book collection digitally.

![License](https://img.shields.io/badge/License-MIT-green)

## 🌟 Features

### 📖 Book Management
- **Add Books**: Manually add books with detailed information
- **Edit & Delete**: Update book details or remove from collection
- **Search & Filter**: Find books quickly with advanced search
- **Categories**: Organize books by genres, authors, or custom categories

### 📱 ISBN Barcode Scanner
- **Camera Integration**: Scan ISBN barcodes using device camera
- **Auto-Fill**: Automatically populate book details from scanned ISBN
- **Offline Support**: Works without internet for manual entry

### 📊 Analytics Dashboard
- **Reading Statistics**: Visualize reading patterns and progress
- **Interactive Charts**: Beautiful charts powered by Recharts
- **Reading Goals**: Track progress towards reading targets
- **Insights**: Get insights about your reading habits

### 🔐 User Authentication
- **Secure Login**: Firebase Authentication for user accounts
- **Personal Collections**: Each user has their own private book library
- **Data Privacy**: Your books are stored securely in the cloud

### 📱 Mobile Responsive
- **Cross-Platform**: Works seamlessly on desktop, tablet, and mobile
- **Touch-Friendly**: Optimized touch interactions for mobile devices
- **Progressive Web App**: Install as PWA for native app experience

## 🛠️ Tech Stack

### Frontend
- **React 19** - Modern React with latest features
- **Vite** - Fast build tool and development server
- **React Router** - Client-side routing
- **Framer Motion** - Smooth animations and transitions

### Backend & Database
- **Firebase** - Backend-as-a-Service
  - Firestore (Database)
  - Firebase Auth (Authentication)
  - Firebase Hosting (Deployment)

### UI & Styling
- **Custom CSS** - Responsive design system
- **Lucide React** - Beautiful icons
- **React Icons** - Additional icon library
- **React Hot Toast** - User notifications

### Development Tools
- **ESLint** - Code linting and formatting
- **Vite Plugin React** - React integration for Vite

## 🔒 Security

- **API Key Protection**: Firebase API keys are restricted to authorized domains
- **User Authentication**: All data access requires authentication
- **Firestore Rules**: Strict security rules ensure users can only access their own data
- **Environment Variables**: Sensitive config stored in environment variables

## 📱 Progressive Web App (PWA)

The app can be installed as a PWA on supported devices:
- **Desktop**: Click "Install" in Chrome/Edge
- **Mobile**: Add to home screen in Safari/Chrome
